Yadoo

Yadoo is a simple reminder app for recurring tasks and events that are easy to forget.

The Problem

Some things are important but happen too rarely to become habits:

Friends' and family members' birthdays
Annual doctor checkups
Car maintenance every few years
Watering plants
Monthly rent payments
Renewing documents and subscriptions

Yadoo was created to solve a problem I personally had: remembering things that don't happen frequently enough to stay on my radar.

The target users are busy people who want to remember these tasks without maintaining a detailed personal calendar.

Product Approach

Yadoo focuses on three principles:

Simplicity
Create a reminder with only the information that is necessary. For example, users select a date with a date picker instead of navigating through a separate calendar.

Accuracy
The main purpose of the app is to make sure recurring tasks are remembered at the right time.

Good UX
I deliberately avoided adding features simply because they were possible. The goal was to build a focused product rather than a feature factory.

A calendar view, for example, is not part of the current version because it isn't necessary for the core use case.

Tech Stack
React Native
JavaScript / TypeScript
Claude Code
Android Emulator

I chose React Native to develop the app for both Android and iOS using a single codebase. Since this is my first mobile application, I chose React Native instead of starting with native Swift development.

Although I use an iPhone, I initially developed and tested Yadoo on Android using an emulator.

Development Process

I managed the development using a Kanban backlog containing:

High-priority features
Bugs
UX improvements
Future ideas

I prioritized work based on its impact on the core user experience.

The application was developed iteratively with AI assistance through Claude Code.

Product Thinking

Yadoo is intentionally small.

The goal was not to build a feature-heavy productivity app, but to identify a specific problem and build a focused solution around it.

The product is based on a simple idea:

People don't necessarily need more information. They need help remembering the right things at the right time.

Future versions may include features such as smarter recurring schedules, notification customization, and a calendar view if they provide meaningful value to users.
